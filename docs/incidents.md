# Журнал типовых инцидентов

| Инцидент | Наблюдаемый признак | Источник диагностики |
|---|---|---|
| Неиспользуемая переменная | Красная проверка pylint | Static analysis |
| Недостаточные права | Deploy не получает OIDC-токен | Deploy to GitHub Pages |
| Битая ссылка | Строгая сборка MkDocs падает | Build documentation |
| Старая версия после успешного деплоя | Браузер показывает прежнее содержимое | URL окружения, SHA запуска, кэш браузера |

В разборе указываются симптом, компонент, доказательство из журнала, причина, исправление и проверка восстановления.
