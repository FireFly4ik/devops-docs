# Эксплуатация

## Штатная публикация

1. Дождитесь успешной проверки `pylint` в Pull Request.
2. Выполните слияние в `main`.
3. Откройте Actions → Publish documentation.
4. Дождитесь успеха заданий `build` и `deploy`.
5. Проверьте главную страницу по URL окружения `github-pages`.

## Ручной перезапуск

Повторную публикацию можно запустить через Actions → Publish documentation → Run workflow.

## Диагностика

Определите отказавший этап и откройте журнал конкретного шага. После исправления проверьте запуск с новым коммитом.
